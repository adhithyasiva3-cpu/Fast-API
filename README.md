# 🏦 Bank CRUD System

A simple Online Banking System developed using **Python, FastAPI, MySQL, HTML, and CSS**.

## 📌 About the Project

This project is a basic banking application that provides separate features for **Users** and **Admins**.

## ✨ Features

### 👤 User
- User Login
- View Account Details
- Check Balance
- Deposit Money
- Withdraw Money
- View Transaction History
- Logout

### 🛡️ Admin
- Admin Login
- Create Bank Account
- View All Accounts
- View All Transactions
- Delete Bank Account
- Logout

## 🛠️ Technologies Used

- Python
- FastAPI
- MySQL
- HTML
- CSS
- Jinja2
